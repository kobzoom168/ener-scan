## 8. ข้อเสนอ (ไม่เกิน 3 ข้อ — รอกบตัดสิน ยังไม่ลงมือ)

### ① ปิด `low_shadow` — ประหยัด ~33฿/เดือน · effort ≈ 0 · ความเสี่ยงต่อลูกค้า = ไม่มี
**หลักฐาน:** flag `OBJECT_CHECK_LOW_SHADOW_ENABLED=true` ยังเปิด เรียกล่าสุด 16 ก.ย. 10:23 · ช่วง A 95 calls $0.2166 (7.8฿/7วัน)
นี่คือ **การทดลองของเราเอง** (สุ่ม 10% ไปเทียบ prompt ประหยัด) ไม่ได้ส่งผลถึงลูกค้าเลย — ปิดได้ทันทีถ้าการทดลองสรุปผลแล้ว **คำถามเดียวที่ต้องตอบก่อน: การทดลองเก็บข้อมูลครบตามที่ตั้งไว้หรือยัง** (ถ้ายัง ควรปล่อยจนครบแล้วค่อยปิด ไม่งั้นเสียข้อมูลที่จ่ายเงินเก็บมาแล้ว)

### ② ขอปลดล็อกเฉพาะการ "วัด" ด่านก่อนสร้างงาน — ยังไม่ลดอะไร แต่คือก้อนใหญ่ที่สุดที่ยังมองไม่เห็น
**หลักฐาน:** 442 calls = 68฿/7วัน = **~291฿/เดือน = 17% ของบิล Pro** และเกือบทั้งหมดคือ `objectCheck.strict` บน **gpt-4.1 (โมเดลแพงสุด)** ยิงกับรูปที่ยัง**ไม่รู้ว่าจะกลายเป็นงานจริงหรือถูกปฏิเสธทิ้ง**
ตอนนี้เราตอบไม่ได้ว่ากี่เปอร์เซ็นต์ของเงินก้อนนี้จ่ายไปกับรูปที่ถูกปัดทิ้ง เพราะ instrumentation `preJobRef` + `PRE_JOB_GATE_TERMINAL` ที่ทำเสร็จและทดสอบแล้วใน W2 **ถูกสั่งห้ามขึ้น Pro**
**ข้อเสนอ:** ขอ Codex พิจารณาปลดล็อกเฉพาะ instrumentation ก้อนนี้ขึ้น Pro (ไม่เปลี่ยน decision/model/call count · เทสต์ผ่านครบ · full gate เขียว) แล้ววัด 7 วัน → ถึงตอนนั้นค่อยตัดสินว่ามีอะไรลดได้จริงไหม **ไม่ใช่ข้อเสนอให้ลดตอนนี้**

### ③ voiceScript (Opus) ~105฿/เดือน — **ไม่เสนอให้ตัด**
เป็นก้อนที่โตเร็วสุด (+143%/วัน) แต่โตเพราะ**ลูกค้าที่จ่ายเงินเพิ่มเท่าตัว** — เป็นต้นทุนที่วิ่งตามรายได้ ไม่ใช่ความสิ้นเปลือง
ถ้าวันหนึ่งจะลดจริง ทางที่ถูกคือ A/B เทียบคุณภาพเสียงกับรุ่นถูกกว่าก่อน ไม่ใช่ปิดทิ้ง — และตอนนี้ยังไม่คุ้มเสี่ยงกับลูกค้ากลุ่มที่จ่ายเงิน

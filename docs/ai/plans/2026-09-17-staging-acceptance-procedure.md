# ขั้นตอนทดสอบบน staging ที่ต้องให้กบทำ (17 ก.ย. 2026)

## ก่อนเริ่ม — ข้อควรระวังที่ Codex เตือน (สำคัญมาก)
1. **บัญชีต้องเกิดหลังเปิดสวิตช์** — ห้ามสร้าง/แอดบัญชีไว้ก่อนแล้วค่อยเปิด มิฉะนั้นจะถูกจัดเป็นลูกค้าเก่าทันที
   ลำดับที่ถูก: เปิดสวิตช์ → **แล้วค่อย** แอดเพื่อน LINE staging ด้วยบัญชีที่ไม่เคยใช้ staging มาก่อน
2. **ห้ามแก้ created_at หรือลบประวัติบัญชีจริงเพื่อให้ผ่าน** — ถ้าบัญชีถูกจัดเป็นเก่า ให้ใช้บัญชีใหม่จริง ๆ แทน
3. ส่งรูป **ทีละรูป รอรายงานจบก่อนส่งรูปถัดไป** (เคสส่งพร้อมกันทดสอบแยกทีหลัง)

# โน้ต conversion 400 คน + แผน scale 10k (จาก AI ภายนอก, 11 ส.ค. 2026)

สถานะ: **ข้อมูลอ้างอิง — กบยังไม่ตัดสินใจ** (กบ: "ไว้เป็นข้อมูล ยังไม่ต้องตัดสิน")
เนื้อหาเต็มอยู่ในแชทกบ 11 ส.ค. — แก่นที่ควรจำ:

1. เปลี่ยนคำขาย 49 จาก "4 ครั้ง" เป็น "ภารกิจเทียบ 4 ชิ้น เลือกชิ้นที่เข้ากับคุณสุด" (ต้องมีการ์ดเทียบจริง ไม่ใช่แค่เปลี่ยนคำ)
2. แบ่งฐาน 400 คนเป็น cohort (ไม่เคยส่งรูป/ฟรีไม่จ่าย/เปิด QR ไม่จ่าย/เคยจ่าย/จ่ายซ้ำ/หาย 30 วัน) → broadcast คนละข้อความ (LINE audience ต้อง ~50+ คน เริ่ม 3-4 กลุ่มใหญ่)
3. funnel รายวัน add→รูปแรก→รายงาน→รูปสอง→paywall→เลือกแพ็ก→QR→จ่าย→จ่ายซ้ำ — วัดค่า ads ต่อ "ผู้จ่ายจริง" ไม่ใช่ต่อ add
4. 399 ห้ามเสนอลูกค้าใหม่ — เสนอผ่านแอดมินเมื่อเห็นพฤติกรรม (คลัง 5-8 ชิ้น / จ่าย 49 ซ้ำ)
5. Scale 10k: อย่าใช้ FB Ads ช่องทางเดียว (Ads 40-50% / referral 20-25% / TikTok 15-20% / influencer 10-15% / SEO 5-10%) · แผน 4-6 เดือน · ถ้า funnel ไม่เสร็จ หยุด scale ที่ 1-2k ก่อน
6. Retargeting Meta ห้ามอัปโหลด LINE user ID ตรง ๆ

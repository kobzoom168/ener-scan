> ลูกเล่น/รูปแบบนำเสนอ (AI 4 ตัว) · demo ล่าสุด: /payment/synergy-demo.html (v3)
> สถานะ: **สเปกพร้อม รอกบเคาะเริ่มสร้างของจริง (~2-3 วัน)**

## หลักการใหญ่ (ฉันทามติทุกรอบ)

1. **เปิดหน้า = คำตอบทันทีใน 5 วินาที**: "วันนี้พกชุดนี้" รูปจริง 2 องค์ใหญ่ ไม่ใช่บทวิเคราะห์
2. **ภาษาสูตรเดียว**: ประโยคแรกบอกทำอะไร (พก/ห้อย/เพิ่ม/เลือก) → ประโยคสอง "เชื่อกันว่า…" · ≤2 ประโยค/กล่อง
3. **ไม่มีตัวเลขหน้าแรก**: แถบ ■■□ 3 ระดับ (เด่นมาก/เด่น/เสริมได้อีก) · คะแนนจริงพับใน "ดูรายละเอียด"
4. **Deterministic**: ผู้ใช้เดิม+วันเดิม+ภารกิจเดิม+คลังเดิม = ชุดเดิมเสมอ (refresh ไม่เปลี่ยน) —
   เปลี่ยนเมื่อ: ข้ามวัน / เลือกภารกิจใหม่ / สแกนชิ้นใหม่
5. เรียกพระว่า **"องค์ที่ N"** (เลน amulet — ขลังกว่า "ชิ้นที่" และไม่ผิดกติกาห้ามระบุชนิด) · กำไล/หิน = "ชิ้นที่ N"

## Interactive (แตะปุ่มเท่านั้น — ทุกตัวห้าม ลาก/เขย่า/วงล้อสุ่ม/RPG)

- **แถบเลือกวัน**: วันนี้ / พรุ่งนี้ / 7 วัน → ชุดบนแท่นเปลี่ยนทันที (JS สลับ ไม่โหลดใหม่)
- **ปุ่มภารกิจ 4 ปุ่ม**: คุยงาน / เดินทาง / เสี่ยงโชค / วันทั่วไป → ระบบเลือกชุดที่คำนวณไว้แล้ว
- **แตะรูปองค์ → ขยาย + บทบาท** ("องค์หลัก: หนุนดวง" 1-2 บรรทัด)
- **ปุ่ม "วันนี้พกชุดนี้"** → บันทึก + นับต่อเนื่อง ("พกตามชุดแนะนำ 3 วันติด") — ห้ามข้อความกดดัน/ขู่ streak ขาด

## Visual: "แท่นจัดชุดพลัง" (ชนะโหวต 4/4 — ไม่ใช่หิ้งพระ/แท่นบูชาจริง เลี่ยงประเด็นศาสนา)

- ชุดแนะนำ 2 องค์วางบนฐานทอง/วงแหวนแสง กลางจอ — องค์หลักใหญ่กว่าองค์เสริม + ป้ายบทบาทใต้รูป
- ชิ้นที่เหลือ = "ชั้นวาง" ด้านล่าง (grid เล็ก แตะดูได้)
- **ปฏิทินพลัง 7 วัน**: แถวเล็ก ศ31 ส1 อา2… แต่ละวันโชว์เลของค์ที่แนะนำ แตะแล้วแท่นเปลี่ยน
- CSS/JS ล้วน ไม่มี canvas หนัก ไม่มีแอนิเมชันยาว (มือถือเก่า + คนวัย 40-60)

## องค์ประกอบความเชื่อ (เฉพาะที่มีหลักคำนวณ)

- ✅ **โทนสีเสริมประจำวัน** — ตารางสีตายตัวในโค้ด (ห้าม AI คิดสีเอง) ใช้คำ "โทนสีเสริมกำลังใจวันนี้" ไม่ใช่ "ต้องใส่"
- ✅ **พลังนำ/พลังเสริมวันนี้** + **คำตั้งใจประจำวัน** 1 ประโยค (gen จากสายเด่น+ภารกิจ)
- ❌ เลขเด็ด/เลขมงคล (ดูสุ่ม เสี่ยงภาพลักษณ์ใบ้หวย) · ❌ ฤกษ์นาที (ไม่มีตำราจริง = มั่ว) ·
  ❌ ทิศละเอียด · ❌ คำขู่ทุกชนิด ("วันนี้พลังตก/ห้ามเดินทาง")

## กลับมาเปิดซ้ำ + แจ้งเตือน

- เปลี่ยนทุกวัน: ชุดแนะนำ / พลังนำ / โทนสี / คำตั้งใจ · **ไม่เปลี่ยน**: คะแนนชิ้น ฉายาคลัง องค์หลัก เหตุผลคู่
- แจ้งเตือน LINE: **opt-in เท่านั้น** เลือกความถี่ได้ (ทุกเช้า/จ-ศ/ปิด) default ไม่ส่ง ·
  ข้อความ ≤2 บรรทัด + ปุ่มเปิดรายงาน · ไม่ส่งซ้ำถ้าวันนั้นเปิดแล้ว · พ่วง Rich Menu ปุ่ม "ชุดพลังวันนี้"
- Monthly Wrapped: สรุปคลังประจำเดือนเป็นภาพเดียว (ฉายาคลัง+องค์หลัก+สถิติ) ไว้แคปแชร์

## การ์ดแชร์อัตโนมัติ 3 แบบ (โลโก้+วันที่+disclaimer เล็ก)

① "ชุดพลังวันนี้ของฉัน" ② "คู่เด่นประจำคลัง" ③ "ฉายาคลังของฉัน"

## สูตรจัดชุดรายวัน (deterministic)

คะแนนเลือกชุด = 60% ตรงภารกิจ + 20% เสริมกันของคู่ (สายต่างกัน) + 15% น้ำหนักวัน/วันเกิด (ตารางตายตัว) + 5% กันซ้ำชุดล่าสุด · seed = userId+dateKey+mission

## ธุรกิจ (ตาม roadmap เดิม)

- ดูตัวอย่างภาพรวมฟรี → รายงานเต็ม **ค่าครู 99** / สมาชิก 399 เปิดได้ 4 ครั้ง/เดือน
- Trigger: มีครบ 3 ชิ้น → preview + ชวนเปิด · ครบ 5 ชิ้น → ภาพรวมคลัง
- ห้ามคำ "พระชนกัน/ตีกัน" — ใช้ "พลังเด่นซ้ำกัน/น้ำหนักไปทางเดียว"

## ตัดออก/พักไว้

เสียงเอฟเฟกต์ (LINE webview จำกัด autoplay) · เขย่า/ลาก/วงล้อสุ่มชิ้น · RPG · แผนที่ดาว ·
ฤกษ์ยาม · เลขมงคล · เข็มทิศ 6 พลัง (ไว้เฟสหลัง)

## ลำดับสร้างจริง (~2-3 วัน)

1. เครื่องคำนวณชุด deterministic + ตารางสี/วัน + LLM เนื้อความ (สูตร 2 ประโยค + fallback)
2. หน้า HTML: แท่นจัดชุด + แถบวัน/ภารกิจ + ปฏิทิน 7 วัน + ชั้นวาง + details ท้าย — ผูก token ต่อลูกค้า
3. ปุ่ม "วันนี้พกชุดนี้" + บันทึก + การ์ดแชร์ 3 แบบ (sharp)
4. จ่ายค่าครู 99 (flow ชำระเดิม) + สิทธิ์ 4 ครั้ง/เดือนใน 399 + trigger 3/5 ชิ้น
5. staging → กบเคาะ → pro

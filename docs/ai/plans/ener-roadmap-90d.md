# Roadmap 90 วัน Ener Scan (ส.ค.-ต.ค. 2026) — สังเคราะห์ AI 4 ตัว + ความเห็น Claude

> จากพรอมต์จัดลำดับแผน A-H (30 ก.ค. 2026) · สถานะ: **รอกบเคาะเริ่มสัปดาห์ 1**
> เกณฑ์: รายได้เพิ่มเร็ว + คนเดียวอัตโนมัติไหว + เสริมกันเอง

## ภาพใหญ่ (ทั้ง 4 ตัวพูดเป็นเสียงเดียว)

เปลี่ยน Ener Scan จาก "บริการสแกนเป็นครั้ง ๆ" → **"ผู้ดูแลคลังพลังส่วนตัว"** ที่มีเหตุผลให้กลับมาทุกวัน
วงจร: สแกน → เก็บเข้าคลัง → เทียบหลายชิ้น (Synergy) → เลือกใช้ประจำวัน (Daily Match) → แชร์ → พาเพื่อนมา → 399

Insight เด็ดสุด (ตัวที่ 4 จากเคสจริงเรา): ลูกค้าซื้อ 49 บาท 5 รอบ/วัน = 245 บาท แต่ไม่ขึ้น 399
→ **399 ไม่ได้แพงไป แต่อธิบายคุณค่าไม่ชัด + จังหวะเสนอไม่ถูก** — นี่คือรอยรั่วที่อุดก่อน

## ลำดับฉันทามติ: **D → G → C → B → A (คู่ขนาน) → F (pre-order) → กำไล organic · พัก E + WhatsApp + eBay**

## เดือนที่ 1 — อุดรอยรั่วรายได้ (ใช้ของที่มี 100%)

### 1. D "ค่าครู" + Spend-to-upgrade (สัปดาห์ 1 — ทำก่อนสุด ทุกตัวให้เป็นอันดับ 1)
- เปลี่ยน copy ทุกจุด: "ซื้อแพ็ก" → **"ค่าครู"** — ตัวอย่างชื่อ: ค่าครูเปิดคำอ่าน 1 ชิ้น (29) ·
  ค่าครูเหมาชุด 4 ชิ้น (49) · **ค่าครูดูแลคลังพลัง 30 วัน (399)**
- ⚠️ ห้ามใช้ "ถวาย/ทำบุญ/บริจาค" ในใบเสร็จ/เงื่อนไข (เสี่ยงเข้าใจผิดเป็นเงินบริจาค) — ใช้ "ค่าครู/ค่าบริการ"
- **Spend-to-upgrade** (ไอเดียแหลมสุดของรอบนี้): ลูกค้าซื้อ 49 รอบ 2 ใน 24 ชม. → ระบบเสนอ
  "ค่าครูที่จ่ายวันนี้หักจากสิทธิ์ 30 วันได้ เพิ่มอีก 301 บาทเปิดคลังพลังเต็มรอบ" (ยอดหักลดตามที่จ่ายจริงในวัน)
  → เคสคุณ 245 บาท/วัน คือคนที่ควรได้ข้อเสนอนี้พอดี
- 399 ต้องมีของที่ "เพิ่มทุกเดือน" ไม่ใช่แค่ "ใช้ได้ 30 วัน": Daily Match เต็ม + Synergy ตามสิทธิ์ +
  สรุปคลังรายเดือน + คลัง/เสียงไม่ถูกปิด

### 2. G Synergy "จัดชุดพลัง" (สัปดาห์ 2-4 — ตัวทำเงินก้อนใหญ่สุด ทุกตัวยก)
- ใช้ข้อมูลสแกนสะสม **ไม่ต้องสแกนใหม่ ไม่มีต้นทุน vision เพิ่ม** — วิเคราะห์ชิ้นทั้งหมดของลูกค้า:
  ภาพรวมคลัง · ด้านที่หนาแน่น/ด้านที่ยังบาง · คู่ที่เสริมกัน · ชุด 2-3 ชิ้นสำหรับงาน/เจรจา/เดินทาง
- ⚠️ ห้ามใช้คำ "พระชนกัน/พลังตีกัน" (สร้างความกลัว = ผิดหลักเรา) → ใช้ "พลังเด่นซ้ำกัน /
  น้ำหนักไปทางเดียวกัน / ยังไม่ครอบคลุมบางด้าน"
- ราคา: add-on **99 บาท/รายงาน** + สมาชิก 399 เปิดได้ 4 ครั้ง/เดือน (ตัวดันคน 49 → 399)
- Trigger อัตโนมัติ: มีครบ 3 ชิ้น → "ระบบเห็น 2 ชิ้นเด่นทางเดียวกัน เปิดดูวิธีจัดชุด" · ครบ 5 ชิ้น → ภาพรวมคลัง
- ได้ 3 เด้ง: กระตุ้นสแกนเพิ่ม + เหตุผลซื้อ 399 + ข้อมูลเก่ากลับมามีค่า

## เดือนที่ 2 — เหตุผลกลับมาทุกวัน + viral

### 3. C Daily Match + streak
- "คุณ × ชิ้นในคลัง × วันนี้ = N%" จากวันเกิด+วันที่+ข้อมูลชิ้น — คำนวณล้วน ไม่เรียก vision = ต้นทุน ~0
- ฟรี: % สั้น ๆ · สมาชิก 399: ชิ้นที่เหมาะสุดวันนี้ + เหตุผลเต็ม + ชิ้นสำรอง + ประวัติ + เสียงอาจารย์
- ⚠️ Streak **อย่าแจกสแกนฟรีบ่อย** (ต้นทุนจริง) → ใช้รางวัลต้นทุนต่ำ: 3 วัน=ตรา · 7 วัน=สรุปสัปดาห์ ·
  14 วัน=Synergy preview · 30 วัน=การ์ดสรุปเดือนไว้แชร์
- เริ่มส่ง 3 วัน/สัปดาห์ก่อน + ให้เลือก opt-in "รับทุกเช้า" — กัน block OA

### 4. B แชร์การ์ด → Referral จริง (เราได้เปรียบ: ระบบ ENER-XXXX มีอยู่แล้ว!)
- ตัวที่ 4 ชี้ถูก: "ส่งหลักฐานแชร์มาแลก" ตรวจยาก โกงง่าย → **ฝัง referral code/ลิงก์ลงบนการ์ดแชร์เลย**
  แล้วนับผ่านระบบชวนเพื่อน ENER-XXXX ที่ LIVE อยู่ → +1 เมื่อเพื่อนแอด+สแกนสำเร็จจริง (กันโกงด้วยของเดิม)
- ปุ่มหลังสแกน: "แชร์การ์ดชิ้นนี้ + โค้ดของคุณ" — เพื่อนเห็นการ์ดสวย → แอดไลน์ → ทั้งคู่ได้สิทธิ์

### 5. A ทายคะแนน (คู่ขนาน — content format ไม่ใช่โปรเจกต์)
- 2-3 คลิป/สัปดาห์ แทรกในตาราง YouTube/Reel เดิม · **70% ทาย "สายพลังเด่น" / 30% ทายคะแนน**
  (ทายสายมีเหตุผลให้สังเกตภาพ ทายเลขดูสุ่ม) · เฉลยจบในคลิปเดียว
- วัด: comment /1,000 engaged views + คนเข้า LINE /1,000 — ถ้าคอมเมนต์พุ่งแต่คนเข้า LINE ไม่มา = ได้นักเดา ไม่ใช่ลูกค้า

## เดือนที่ 3 — ทดลองของใหม่แบบเสี่ยงต่ำ

### 6. Lifecycle Trigger Engine (ไอเดียใหม่ที่แหลมสุดจากรอบนี้ — ขยายจาก renewal reminder ที่มี)
| พฤติกรรม | ข้อเสนออัตโนมัติ |
|---|---|
| สแกนฟรีแรกเสร็จ | ชวนเปิดชิ้นที่สองวันนี้ |
| มี 3 ชิ้น | Synergy preview |
| ซื้อ 49 รอบสอง | Spend-to-upgrade 399 |
| หาย 7 วัน | Daily Match ของชิ้นเดิม |
| ได้คะแนนสูง/ขึ้นคลิป | ชวนแชร์พร้อม referral |
| สมาชิกเหลือ 5 วัน | สรุปสิ่งที่ใช้ + คุณค่าที่จะหาย |
- ทุก trigger ต้องวัดรายได้ ไม่ส่งเพราะส่งได้

### 7. F Home Scan — pre-order ก่อนสร้าง
- ยังไม่สร้างระบบ! เปิดขาย "ตรวจมุมวางพระจากรูป 1 มุม ค่าครู 49" ให้ลูกค้าเดิมแบบ waitlist
- เกณฑ์สร้างจริง: จ่ายจริง ≥10 ราย หรือ conversion >15% จากคนกดดู — ไม่ถึง = พักโดยไม่เสียดาย

### 8. กำไลหิน — ทดสอบ organic ก่อนยิงแอด
- ซีรีส์คลิปกำไล 10-20 ตัวจากข้อมูลที่มี วัด "คนเข้า LINE /1,000 views" เทียบคลิปพระ — ชนะค่อยยิงแอด 500-1,000

## พัก/ตัด (ฉันทามติ 4 ตัว)
- **E ไพ่ยิปซี**: พัก ≥90 วัน — เจือจางแบรนด์ "อ่านพลังจากวัตถุจริง" เป็น "บอทดูดวงทั่วไป" + ไม่ใช้ asset หลัก
  อนาคตกลับมาเป็น "โบนัสรายเดือนของสมาชิก" ได้
- **WhatsApp สิงคโปร์**: พัก — ตลาดไทยยังโตได้อีกมาก (LINE ดูดวง traffic +66% H1/2568)
- **eBay**: แยกเป็นธุรกิจ Ener Bridge ตามเดิม (กบทำเฟส 0 เองอยู่แล้ว) — ไม่ใช้เวลาชุดเดียวกับ Ener Scan

## ไอเดียใหม่เข้าคลัง (ยังไม่จัดคิว — หยิบเมื่อของหลักนิ่ง)
- **Ener Vault** คลังพลังส่วนตัว (= "คลังพระของฉัน" ใน BACKLOG เดิม — ยกความสำคัญขึ้นเพราะสร้าง switching cost ให้ 399/รายปี)
- **ช่องว่างพลังในคลัง** ("ด้านเมตตายังบาง") → กระตุ้นกลับไปสแกนของที่บ้านเพิ่ม
- **Ener Index** สถิติมหาชนรายสัปดาห์/เดือน ("เดือนนี้ 1,204 ชิ้น สายคุ้มครองขึ้นอันดับ 1, เกรด S 18 ชิ้น") — คอนเทนต์+social proof ที่ใครก็เลียนแบบไม่ได้
- **Gift Scan** ซื้อสิทธิ์เป็นของขวัญ (วันเกิด/ปีใหม่/คนเพิ่งได้พระใหม่)
- **Bulk Voucher B2B** ร้านพระ/กำไลซื้อสิทธิ์สแกน 100 ใบแถมลูกค้า — รายได้ล่วงหน้า + ลูกค้าใหม่ฟรี
- **รายงานพลังรายเดือนส่วนตัว** 99-149 หรือรวมใน 399
- **Collector Annual Pass** 999-1,290/ปี เสนอเฉพาะลูกค้าพิสูจน์แล้ว (ซื้อ 49 ≥3 รอบ / มี ≥8 ชิ้น)
- **ส่องออร่าคู่ชีวิต** คน+ชิ้น 59 บาท (Alignment %)

## จุดตายที่ต้องจำ (ตรงกันทุกตัว)
1. เปิดของใหม่เร็วกว่า retention = ตาย — กฎ 90 วัน: vertical ใหม่ไม่เกิน 1 (F แบบ pre-order เท่านั้น)
2. ห้ามใช้ความกลัวขาย ("วันนี้ห้ามออกจากบ้าน/ไม่พกจะพลาด") — ทำลาย trust ถาวร
3. Persona อาจารย์: คุมโทนได้ แต่ห้ามยืนยันเท็จเชิงขั้นตอน ("อาจารย์นั่งตรวจเองทุกชิ้น/จับพลังสด")
4. อย่าแจก full scan เป็นรางวัลทุกกิจกรรม (ต้นทุนจริง) — ใช้ preview/badge/summary
5. คำตอบ/เสียงซ้ำจนจับได้ = ศรัทธาล่ม — คลังคำต้อง random หลากหลาย (ทำแล้วฝั่ง YT hook/CTA — ขยายไป consult ด้วย)
6. PDPA: consent แยกส่วน (ผลส่วนตัว/การตลาด/เผยแพร่/สถิติรวม) — จุดที่เราควรเก็บงานเพิ่ม
7. Unlimited ต้องรู้ต้นทุนต่อสมาชิก + fair-use

## KPI 90 วัน
- รายได้ต่อผู้ใช้จ่าย +25% · คนซื้อ 49 รอบสองได้ข้อเสนอ 399 ครบ 100% ·
  คนมี ≥3 ชิ้น ซื้อ Synergy/อัปเกรด ≥10-15% · ลูกค้าใหม่จาก referral ≥10-15% ·
  เปิด product ใหม่เต็มรูปแบบไม่เกิน 1 ตัว

# ไพ่ยิปซีถามในแชท ("ถามอาจารย์ เปิดไพ่ตอบ") — แผนเต็ม

> สถานะ ณ 29 ก.ค. 2026: **สังเคราะห์จาก AI 4 ตัวเสร็จ รอกบเคาะ 5 ข้อ — ยังไม่ได้สร้าง**
> ที่มา: ไอเดียกบ 24 ก.ค. → พรอมป์ถาม AI 4 ตัว → Claude สังเคราะห์รวมข้อจำกัดระบบจริง

## 1. คอนเซปต์ (กบเคาะแล้ว)
ลูกค้าพิมพ์คำถามแนวดวง/พลังงานในแชท → **โค้ดสุ่มไพ่จริง** (ไม่ใช่ AI เลือก) →
ส่งรูปไพ่ใบจริง + ชื่อไพ่ + AI แปลไพ่ตามคำถาม **ยึดความหมายไพ่ที่กำหนดเท่านั้น
ห้ามใช้ความรู้ทาโรต์จากความจำโมเดล** (เข้ากรอบห้ามมโนที่วางไว้แล้ว) · ฟรีวันละ 2 คำถาม

## 2. ฉันทามติ AI 4 ตัว (เห็นตรงกันหมด)
1. **เริ่ม 22 ใบ (Major Arcana)** แล้วค่อยขยาย 78 เมื่อมีเหตุผล (คำตอบเริ่มซ้ำ/มียอดจ่ายจริง)
2. **1 ใบต่อคำถาม** — spread 3 ใบเก็บเป็นของขายเฟสหลัง ("อ่านลึก 3 ใบ")
3. **ไม่มีไพ่กลับหัว แต่ทุกใบต้องมี "ด้านส่งเสริม + ด้านต้องระวัง"** — ไม่หวานล้วน ดูจริง ไม่ขู่
4. **Template ต่อใบ**: แก่นความหมาย 1 ประโยค + คำสำคัญ 3-5 + ด้านส่งเสริม/ด้านระวัง +
   ความหมายแยกหมวด (งาน/เงิน/รัก/สุขภาวะ*/ทั่วไป-ตัดสินใจ) + คำแนะนำทำได้จริง 1-2 ข้อ +
   **energy_mapping คะแนน 6 แกน Ener ต่อไพ่** (คีย์โยงพระในคลังอัตโนมัติ) + allowed/forbidden phrases
   (*ใช้คำ "สุขภาวะ-การดูแลตัวเอง" ไม่ใช่ "สุขภาพ" เชิงทำนายโรค)
5. **AI pipeline กันมโน**: จัดหมวดคำถาม → สุ่มไพ่ → ส่งเฉพาะ JSON ไพ่ใบนั้นให้โมเดล →
   ตอบเป็น JSON พร้อม evidence_keys อ้างฟิลด์จริง → ตรวจก่อนส่ง (ไม่มี evidence = reject gen ใหม่) ·
   คำตอบ 4-7 บรรทัด ห้าม yes/no ฟันธง
6. **Guardrail ตรวจก่อนสุ่ม+ก่อนหักสิทธิ์** — ลิสต์ปฏิเสธ: วินิจฉัยโรค/การรักษา · ความตาย-อายุขัย ·
   หวย-พนัน · คดีความ · ตั้งครรภ์-เพศลูก · คนหาย · อ่านใจ/กล่าวหาบุคคลที่สาม (นอกใจ/ทำของ) ·
   ลงทุนหนัก-กู้เงินฟันธง · ความรุนแรงในครอบครัว · ผู้เยาว์ · **ทำร้ายตัวเอง = หยุด flow ไพ่
   เข้าสายด่วน 1300 ห้ามขายอะไรต่อ** — มีชุดประโยคเลี่ยงโทนอาจารย์ครบใน raw answers
7. **UX**: สรุปคำถามให้แคบ (ค่าเริ่มต้นกรอบ 90 วัน ไม่รับ "ทั้งปี" ด้วยใบเดียว) →
   "ตั้งจิตสักครู่ครับ" + ปุ่ม [พร้อมแล้ว เปิดไพ่] → หน่วง 1-3 วิ → รูปไพ่ → คำแปล →
   **โยงพระในคลัง** ("ไพ่เน้นพลัง X อาจารย์เห็นว่าชิ้น Y ในคลังคุณสอดคล้อง") + ปุ่ม
   [ดูชิ้นแนะนำ/ถามต่อ] · ไม่ให้เลือกไพ่เอง (อาจารย์เปิดให้ = ขลังกว่า)
8. **ถามต่อจากไพ่เดิมได้ 2 ครั้ง ไม่หักสิทธิ์ ไม่สุ่มใหม่** (pattern Onehora)
9. **โยงคลังพระ = differentiator ใหญ่สุด** ที่แอปไพ่ทั่วไปไม่มี — วงจร: ถามเรื่องกังวล →
   เปิดไพ่ → เห็นพลังที่ต้องเสริม → พบชิ้นในคลัง → กลับไปดูรายงาน/สแกนเพิ่ม

## 3. จุดที่ AI แนะนำต่างจากที่กบเอียงไว้ (ต้องเคาะ)
| ประเด็น | กบเอียงไว้ | AI แนะนำ | ความเห็น Claude |
|---|---|---|---|
| ล็อกคำถามซ้ำ | ล็อกต่อวัน | **ล็อกต่อหัวข้อ 7 วัน** (topic_key จาก AI classify — "เขาจะกลับมาไหม"="คืนดีแฟนเก่า" ประโยคไหนก็ล็อก) + ปลดก่อนได้ถ้ากด "มีข้อมูลใหม่" | เห็นด้วย 7 วัน — ล็อกแค่วันเดียวรอเที่ยงคืนสุ่มใหม่ได้ ระบบดูไม่ขลัง |
| ฟรี 2/วันถาวร | 2/วัน | **2/วันเฉพาะ Beta 30 วัน** แล้วลดเหลือ 1/วัน — เหตุผลแรง: 2/วัน = 60/เดือน สูงกว่าพฤติกรรมจริง 7 เท่า → คำถามเดี่ยวจะขายไม่ออก · เก็บเงินจาก "ความลึก" แทน: อ่านลึก 3 ใบ 29฿ / เทียบทางเลือก A-B 29฿ / ไพ่ติดตามผล 72 ชม. 19฿ / รวมในแพ็ก 399 | เห็นด้วย — ตรงบทเรียน Free→Paid ที่เพิ่งสรุป (กำแพงจำนวนครั้งไม่ทำงาน ความลึกทำงาน) |
| รูปไพ่ | กบถ่าย/อัปรูปไพ่ยิปซีจริง | ⚠️ **ลิขสิทธิ์**: ถ่ายสำรับที่ซื้อมา (เช่น Rider-Waite ฉบับพิมพ์ใหม่) ใช้เชิงพาณิชย์ = เสี่ยง — ทางปลอดภัย: วาด/gen เอง หรือสำรับที่ระบุสิทธิ์พาณิชย์ชัด | แนะนำ **gen ไพ่ธีม Ener เอง 22 ใบ** (กบ gen รูปเก่งอยู่แล้ว) — ได้เอกลักษณ์แบรนด์+ตัดปัญหาสิทธิ์ขาด |
| เปิดเผยว่าเป็น AI | ลูกค้าต้องไม่รู้ | ตัวหนึ่งยก ETDA/สคบ.: ควรแจ้ง "ระบบอัตโนมัติ" อย่างน้อยครั้งเดียวใน ToS/onboarding (ไม่ต้องย้ำในแชท) | ยกให้กบตัดสิน — compromise ได้: ใส่ใน Terms/หน้า LIFF เงียบ ๆ โดย persona ในแชทคงเดิม |

## 4. โมเดลเงิน (หลัง Beta — ปรับจากคำแนะนำรวม + ราคาตลาดไทย)
- ตลาดจริง: คำถามเจาะจง 15-99฿ · แพ็กหลายคำถาม 79-259฿ · Labyrinthos unlimited 399฿/เดือน
- เสนอ: ฟรี 1-2/วัน (ตัดสินจากข้อมูล Beta) · **อ่านลึก 3 ใบ 29฿** (ตัวขายหลัก) ·
  แพ็ก 29/49 เดิมพ่วงสิทธิ์คำถามเพิ่ม · **สมาชิก 399 ได้ไพ่วันละ 2 + อ่านลึกรายเดือน**
  (เพิ่ม perceived value แพ็กเดิม) · **ไม่ทำ "ถามไม่จำกัด"** (ต้นทุน+พฤติกรรมหมกมุ่น)

## 5. ระบบ (โครงเทคนิค — เข้ากับของที่มี)
- คลังไพ่: `src/config/tarotDeck/` JSON ต่อใบ + version · รูปเสิร์ฟจาก repo/R2
- Intent: ต่อยอด webhook เดิม — 7 กลุ่ม (CARD_READING / AMULET_KNOWLEDGE / SCAN / INVENTORY /
  FOLLOWUP / SAFETY / CLARIFY) · ก้ำกึ่ง → ปุ่มถามกลับ [เปิดไพ่/อ่านพลังวัตถุ/ถามข้อมูล]
- สุ่ม: server-side seed = user+topic_key+cycle+deckVersion · snapshot คำตอบ (เปิดซ้ำได้เดิมเป๊ะ)
- โควตา: redis เหมือน free scan · ถามต่อ 2 ครั้งใช้บริบทไพ่เดิมไม่หักสิทธิ์
- โยงพระ: ไพ่มี energy_mapping 6 แกน → จับคู่กับคะแนนแกนชิ้นในคลัง (โครง byAxis มีแล้วใน liff)
- Log ทุก reading (question/card/seed/versions/answer/safety) — ตรวจย้อนหลังได้
- ตัวตรวจแชท 06:00 เพิ่มเกณฑ์ตรวจคำตอบไพ่ (ห้ามฟันธง/ห้ามหลุดลิสต์อันตราย)

## 6. แผนสร้าง (MVP ~1 สัปดาห์ ไม่รวมเวลาเตรียมรูป)
1. คอนเทนต์ไพ่ 22 ใบ — Claude ร่างตาม template → กบรีวิว (Claude ~1 วัน + กบรีวิว)
2. รูปไพ่ 22 ใบ — กบ gen ธีม Ener (spec: 2:3 แนวตั้ง 800×1200 กรอบ/พื้นเดียวกันทั้งสำรับ ชื่อไฟล์ 01-22)
3. ระบบ: guardrail → intent → สุ่ม+lock → UX flow → โยงคลัง → โควตา (~2-3 วัน)
4. Beta ฟรี 2/วัน 30 วัน → วัด: คนถาม / หมวดคำถาม / อัตรากดดูพระแนะนำ / สแกนเพิ่มหลังเปิดไพ่ /
   ชน guardrail → ค่อยเคาะราคา
5. เฟสหลัง: อ่านลึก 3 ใบ / ไพ่ติดตาม 72 ชม. / ขยาย 78 ใบ

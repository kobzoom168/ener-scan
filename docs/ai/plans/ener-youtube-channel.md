# แผนช่อง YouTube "Ener scan พลัง" — จากสแกนรายวันสู่ช่องที่คนรอดู

> สังเคราะห์จากคำตอบ AI 4 ตัว (30 ก.ค. 2026) + ความเห็น Claude + ข้อมูลจริงในระบบ
> สถานะ: **รอกบเคาะ 3 ข้อท้ายไฟล์** · ระบบปัจจุบัน: Shorts อัตโนมัติทุกชิ้น ≥7.5 (~5-10 คลิป/วัน)
> เสียงโคลนกบ + สคริปต์ "ชิ้นนี้จากคุณ… → ความเชื่อ → คะแนน → เด่นทางไหนดันทางนั้น"

---

## 1. ฉันทามติของ AI ทั้ง 4 ตัว (เห็นตรงกันหมด)

1. **จุดแข็งที่คู่แข่งไม่มี = ข้อมูลสแกนจริง ~40 ชิ้น/วัน** — อย่าทำช่องเป็น "แคตตาล็อกผลสแกน"
   ให้เป็น "รายการประจำ": มีอันดับ มีสถิติ มีของหายากให้รอลุ้น → คนถึงจะ subscribe
2. **ความเสี่ยงอันดับ 1 = repetitive / mass-produced content** — คลิปโครงเดียวกัน เสียงเดิม
   เปลี่ยนแค่รูปกับคะแนน วันละ 5-10 คลิป เข้าข่าย Spam policy ของ YouTube (มีลิงก์ Google Help ยืนยัน)
   → เสี่ยงโดนกดการกระจาย + ตัดสิทธิ์ monetize ทั้งช่อง + คนดูเบื่อกดเลิกติดตาม
3. **Hook 2 วินาทีแรกห้ามเปิดด้วย "ชิ้นนี้จากคุณ…"** (ทั้ง 4 ตัวพูดเหมือนกัน!) —
   คนไม่รู้จักลูกค้าคนนั้น จะปัดทิ้งทันที → เปิดด้วยความหายาก/อันดับ/จุดผิดคาด แล้วค่อยเครดิตชื่อวินาทีที่ 2-4
4. **ซีรีส์อันดับคือเครื่องสร้าง subscriber**: Top 3 ประจำวัน · S-Alert (เกรด S โผล่) ·
   ดวลพลัง 2 ชิ้น · สรุปสถิติ 7 วัน (วันอาทิตย์)
5. **CTA ไม่ขายทุกคลิป** — สัดส่วน ~50% ชวนติดตาม / 30% ชวนส่งชิ้นมาสแกน / 20% ชวนคอมเมนต์

**จุดที่เห็นแย้งกัน — ความถี่:** ตัวหนึ่งบอก 5-10/วันคือข้อดี (โอกาสจับรางวัล algorithm) อีกสามตัวบอกลดเหลือ 2-4/วัน
**ข้อสรุปของผม: 3-4 คลิป/วัน แต่คนละฟอร์แมต** — ปริมาณที่ปลอดภัยต่อ policy + คนดูไม่เบื่อ + ยังได้ทดสอบ algorithm ทุกวัน

## 2. ข้อเท็จจริงสำคัญที่ AI ตัวสุดท้ายชี้ (ตรวจแล้วจริง)

- **ลิงก์ใน description และ pinned comment ของ Shorts กดไม่ได้** — ลิงก์ LINE ที่เราใส่อยู่ตอนนี้
  คนดูมือถือกดไม่ได้เลย! ช่องทางที่กดได้จริง: ① ลิงก์แรกบนหน้าช่อง (โชว์ข้างปุ่ม Subscribe)
  ② Related video (วิดีโอแนวนอนที่แปะใต้ชื่อช่องใน Shorts — description ของตัวนั้นลิงก์กดได้)
  → CTA เสียงต้องพูดว่า **"กดชื่อช่อง แล้วแตะลิงก์แรก"** ไม่ใช่ "กดลิงก์ข้างล่าง"
- **Views ของ Shorts นับทุกการเริ่มเล่น** (ตั้งแต่ มี.ค. 2025) — ตัวชี้วัดจริงคือ **Engaged views +
  Stayed to watch + Average % viewed** ใน Studio
- **เสียงโคลนตัวเองไม่ต้องประกาศ AI อัตโนมัติ** แต่ควรติ๊ก altered/synthetic content ตอนอัป
  (YouTube API มี field ให้ตั้งได้) และหลีกเลี่ยงประโยคที่ทำให้เข้าใจว่าอาจารย์นั่งอ่านสด ๆ ต่อหน้า
- **YPP ไทย**: ขั้นแรก 500 subs + 3M Shorts views/90 วัน — ไม่ใช่เป้าหลัก ช่องนี้คือเครื่องพาคนเข้า LINE

## 3. แผนทำจริง (เรียงตามลำดับ — ทุกข้อ automate ได้ในระบบเดิม)

### Phase 1 — สัปดาห์นี้ (แก้ของที่มีอยู่ ไม่สร้างใหม่)
1. **Hook ใหม่ 6 แบบ สุ่มสลับ** (แก้ SHORT_SYSTEM): ความหายาก ("วันนี้จาก 40 ชิ้น มีชิ้นเดียวที่แตะ 8.8") /
   อันดับ / จุดผิดคาด ("เกรด A แต่มีด้านหนึ่งพุ่งระดับ S") / คำถาม / สถิติ / เหตุการณ์ —
   แล้วค่อย "ชิ้นนี้จากคุณ…" วินาทีที่ 2-4 · โครงเล่า + CTA ปิดท้าย สุ่มจากหลายชุด ลด "ความเป็นแม่พิมพ์"
2. **ลดปริมาณรายชิ้น**: จาก "ทุกชิ้น ≥7.5" → **คัดวันละ 2-3 ชิ้นเด่นสุด** (กติกา: คะแนนสูงสุดของช่วงเวลา +
   สายพลังไม่ซ้ำกับคลิปก่อนหน้า + เว้นห่าง ≥4 ชม.) — ชิ้นที่เหลือเก็บเป็นวัตถุดิบ Top 3 / สถิติ ไม่เสียเปล่า
   (โบนัส: เครดิต ElevenLabs ลดจาก ~10 → ~4 คลิป/วัน)
3. **S-Alert**: เกรด S (≥8.9) โผล่เมื่อไหร่ → คลิปพิเศษทันที ธีมเสียงตื่นเต้นขึ้น title "เกรด S มาแล้ว" (trigger อัตโนมัติ 100% — S หายาก ~1-2% ยิ่งนานยิ่งขลัง)
4. **CTA เสียงปิดท้ายแบบสุ่ม 3 แบบ**: ชวนติดตาม ("พรุ่งนี้มาดูกันว่าชิ้นไหนขึ้นอันดับหนึ่ง") /
   ชวนสแกน ("อยากรู้ชิ้นของคุณ กดชื่อช่องแล้วแตะลิงก์แรกครับ") / ชวนลุ้น ("ชิ้นของคุณอาจติดท็อปวันพรุ่งนี้")
5. **ติ๊ก synthetic content** ในตัวอัป ener-ai + ท้าย description ใส่บรรทัด
   "อ่านตามแนวความเชื่อ ไม่รับรองผล ไม่ตัดสินแท้เก๊หรือมูลค่า" (มีแล้วบางส่วน — เสริมให้ครบ)
6. **Redirect วัดผล**: `scan.my-ener.uk/yt` → 302 ไป LINE + นับคลิก → รู้ว่า YouTube พาคนเข้า LINE กี่คน
   (ลิงก์นี้ใช้เป็นลิงก์แรกหน้าช่อง)
7. **หน้าช่อง (กบทำมือครั้งเดียว)**: ลิงก์แรก = ลิงก์ redirect · แบนเนอร์ "ชิ้นเด่นวันนี้ • S-Alert • สรุปอันดับทุกสัปดาห์" ·
   About ใส่กติกาช่อง (ไม่ตัดสินแท้เก๊ ไม่ประเมินราคา ไม่รับรองผล)

### Phase 2 — สัปดาห์ที่ 2-3 (ฟอร์แมตอันดับ)
8. **Top 3 ประจำวัน** (~19:30-20:30): การ์ด 3 ใบเรียงอันดับ 3→2→1 เก็บแชมป์ไว้ท้าย
   เสียงพากย์เล่าอันดับ — ระบบรวบอัตโนมัติจากชิ้นของวัน (คลิปเดียวใช้เสียง ~เท่าคลิปรายชิ้น)
9. **สรุปพลัง 7 วัน** (อาทิตย์ค่ำ): "สัปดาห์นี้สแกน N ชิ้น เกรด S x ชิ้น สายที่เด่นสุดคือ… คะแนนสูงสุด 9.1" —
   สถิติจริงจากระบบ ตัวเดียวที่ช่องมูอื่นเลียนแบบไม่ได้
10. **ดวลพลัง 2 ชิ้น** (สัปดาห์ละ 2-3): จับคู่ชิ้นคะแนนใกล้กันแต่สายต่างกัน การ์ดซ้าย-ขวา
    "ถ้าต้องเลือกใช้เจรจา คุณเลือกฝั่งไหน" → กระตุ้นคอมเมนต์ (จับคู่อัตโนมัติได้)
11. **วิดีโอแนวนอน "วิธีส่งรูปมาสแกนฟรี"** 45-60 วิ 1 ตัว (ทำครั้งเดียว) → ตั้งเป็น Related video
    ของ Shorts (ลิงก์ LINE ใน description ตัวนี้กดได้) — ตั้งผ่าน Studio เป็นรายคลิปสำคัญ

### Phase 3 — เดือนที่ 2 (วัดและปรับ)
12. เก็บ KPI ต่อฟอร์แมต: Engaged views · subs ต่อ 1,000 engaged views · คลิก /yt ต่อ 1,000 ·
    สแกนใหม่ · ซื้อแพ็ก — โพสต์ครบ ~30 คลิปแล้วใช้ **ค่ากลางของช่องตัวเอง** ตัดสิน:
    ฟอร์แมตไหนเกินค่ากลาง → เพิ่ม / ต่ำกว่า 5 คลิปติด → เปลี่ยน hook หรือพัก
13. ตารางเป้าระยะยาว: เช้า "พลังเด่นวันนี้" · กลางวัน รายชิ้น/S-Alert · ค่ำ Top 3 / ดวล · อาทิตย์ สรุป 7 วัน

## 4. เรื่องที่ต้องระวัง (จากทั้ง 4 ตัว + กติกาเราเอง)

- ห้ามเคลมผล: "พกแล้วรวยแน่" "กันภัย 100%" "เห็นผลใน 7 วัน" — ผิดทั้งกติกาเราและ policy YouTube
- ห้ามให้ดูเหมือน "อาจารย์นั่งจับพลังสด ๆ" — ใช้ "ผลอ่านของ Ener ขึ้นเด่นด้าน…" / "ตามแนวความเชื่อ…"
- **ชื่อลูกค้าบนคลิป**: AI ตัวสุดท้ายเตือนเรื่อง privacy (YouTube รับเรื่องร้องเรียนถ้าเผยชื่อโดยไม่ยินยอม)
  ทางเลือก: ชื่อเต็ม (ปัจจุบัน) / ชื่อย่อ "คุณ T." / "จากผู้ใช้ท่านหนึ่ง" — **รอกบเคาะ** (ดูข้อเคาะ ②)
- อย่าเพิ่มความถี่เพียงเพราะวัตถุดิบเหลือ — เพิ่มเมื่อ KPI บอกว่าฟอร์แมตไหนดีจริง

## 5. ต้นทุน

ทั้งแผนไม่มีค่าใช้จ่ายใหม่ — ffmpeg/upload ฟรี · แคปชัน/สคริปต์ LLM ~สตางค์/คลิป ·
เสียง ElevenLabs **ลดลง** จากเดิม (คัด 2-3 รายชิ้น + Top 3 + สรุปสัปดาห์ ≈ 4-5 เสียง/วัน จากเดิม ~10)

## 6. ข้อให้กบเคาะ (3 ข้อ)

① **ความถี่+เกณฑ์**: ตามแผนนี้ = วันละ 3-4 คลิป (รายชิ้นเด่น 2-3 + ซีรีส์ 1) แทน "ทุกชิ้น ≥7.5" — เอาไหม
② **ชื่อลูกค้าบนคลิป YouTube**: ชื่อเต็ม (เดิม) / ชื่อย่อ "คุณ T." / ไม่ระบุ — แนะนำชื่อย่อ (ปลอдภัย privacy แต่ยังมีเครดิต)
③ **วิดีโอแนวนอน "วิธีส่งรูปมาสแกน"**: กบอัดเองหน้ากล้อง หรือให้ระบบทำจากการ์ด+เสียงโคลน (ผมทำให้ได้)

# ต่อยอดฐานข้อมูลรุ่น/วัด → VDO + รายได้ (สังเคราะห์ AI 4 ตัว + Claude)
(7 ส.ค. 2026 — คู่กับ ener-object-info-gate.md ที่เป็นตัวเก็บข้อมูล · รอกบเคาะลำดับ)

## สิ่งที่ทั้ง 4 ตัวเห็นตรงกัน
1. **ของมีค่าจริงคือฐานข้อมูล ไม่ใช่คะแนน** — รูปจริง+รุ่น/วัด+คะแนน+พฤติกรรมเจ้าของ ยิ่งสะสมยิ่งลอกยาก
2. **คอนเทนต์สถิติอัตโนมัติ** ทำได้ทุกวันไม่ต้องถ่ายใหม่ ดึงคนมาสแกน → ฐานโตเอง (flywheel)
3. **รายได้ตัวแรก = ใบรายงานพลัง PDF แนบขาย** (100-300 บาท/ใบ, QR ตรวจสอบ, disclaimer ไม่การันตีแท้เก๊/ราคา) — เสี่ยงต่ำสุด ทีมคนเดียวทำได้ อัตโนมัติทั้งเส้น
4. **ถัดไป = จับคู่คนหา-คนมี (matching)** ไม่ถือของ ไม่ชี้ขาดแท้เก๊ ค่าคอม 5-10% → ค่อยโตเป็น marketplace
5. **ระวัง**: PDPA/ขอ consent ใช้รูปทำคอนเทนต์ · ห้ามคำ รับประกัน/แท้ 100%/รวยแน่นอน · ค้าของเก่าเกิน 600k ต้องรายงาน ปปง. · ติดป้าย "เจ้าของแจ้ง" ทุกจุด

## ช่องข้อมูลที่ควรเก็บ (คัดจากลิสต์รวม ~15 ช่องของ 4 ตัว)
**ถามในเกต (เพิ่มจากแผนเดิมนิดเดียว — Claude เบรก: ห้ามฟอร์มยาว ลูกค้าหนี):**
- ชื่อพิมพ์/วัด/รุ่น/ปี (พิมพ์อิสระ 1 ข้อความ — ตามแผนเดิม)
- จุดประสงค์ที่พก (ปุ่ม เลือกได้: ค้าขาย/งาน/ความรัก/คุ้มครอง/เสี่ยงโชค/สะสม)
- เก็บสะสม หรือ เปิดรับข้อเสนอ (ปุ่ม 2 อัน — ประตูสู่ matching)
**ขอครั้งเดียวต่อคน (ไม่ใช่ต่อชิ้น):** ยินยอมให้ใช้รูปทำคอนเทนต์/โชว์คลังสาธารณะ (PDPA — จำเป็นก่อนทำซีรีส์/marketplace)
**ไม่ต้องถาม (ระบบมีแล้วจาก classifier):** หมวด/วัสดุ/เลน — objectForm 17 แบบ + motifFamily มีอยู่แล้ว
**ไว้ทีหลัง:** ราคาที่ได้มา/จังหวัด/อายุครอบครอง (ถามตอนลูกค้ากดสนใจขาย ไม่ถามหว่าน)

## ซีรีส์ VDO อัตโนมัติ (เรียงตามเริ่มได้เร็ว — ต้องรอข้อมูลรุ่นสะสม ~2-4 สัปดาห์ก่อนถึงมีเนื้อ)
1. **Top ประจำวัน/สัปดาห์**: "วันนี้คนไทยส่งพระอะไรมาสแกนมากสุด" / "Top 5 คะแนนโชคลาภสัปดาห์นี้" (query+template เดิมของ YT pipeline)
2. **"รุ่นนี้พบในระบบแล้ว N องค์"**: นับสะสมต่อรุ่น — สร้าง FOMO อยากส่งของตัวเองเข้าระบบ
3. **"คนพกรุ่นนี้เพื่ออะไร"**: สถิติจุดประสงค์จริงต่อรุ่น ("หลวงปู่ทวด: คุ้มครอง 51% เดินทาง 22%") — ใช้ช่องจุดประสงค์ที่เก็บใหม่
4. **ชุดพกยอดนิยมวันนี้**: ต่อยอด Synergy ที่มีอยู่
5. **ของหายาก**: "ทั้งระบบมีองค์เดียว" — เจ้าของภูมิใจ คนอื่นอยากอวด
**ที่ Claude เบรก (ดราม่าสูง ไม่ทำ):** ซีรีส์ "วัดเดียวกันพลังต่างกันลิบ" / "เจ้าของแจ้ง vs พลังจริง" — สื่อเป็นนัยเรื่องเก๊ ขัดเส้นแดง แม้ 2 ตัวเสนอมา (อีกตัวก็เตือนเองว่าห้ามเทียบวัดเชิงลบ)

## ลำดับรวม (เสนอ)
| เฟส | ทำอะไร | หมายเหตุ |
|---|---|---|
| 0 | เกตเก็บข้อมูล (ener-object-info-gate.md + ช่องใหม่ 2 ปุ่ม + consent ครั้งเดียว) | ฐานของทุกอย่าง ~1-2 วันงาน |
| 1 | ซีรีส์ Top ประจำวัน เสียบเข้า YT/FB pipeline เดิม | เริ่มเมื่อข้อมูลรุ่นมีพอ (~2-4 สัปดาห์หลังเกต live) |
| 2 | ใบรายงานพลัง PDF แนบขาย (ค่าครูรายใบ) | รายได้แรก อัตโนมัติทั้งเส้น |
| 3 | ซีรีส์ N องค์ / คนพกเพื่ออะไร / ชุดยอดนิยม | ข้อมูลหนาแล้ว |
| 4 | Matching คนหา-คนมี (จากปุ่ม "เปิดรับข้อเสนอ") | ค่าคอม ไม่ถือของ |
| 5 | B2B สถิติร้านพระ / Dealer / ต่างประเทศ (โยง Ener Bridge) | ฐานใหญ่ค่อยทำ |

## เส้นแดง (รวมทุกตัว)
ไม่การันตีแท้เก๊/ราคา · คะแนนไม่ผูกรุ่น · "เจ้าของแจ้ง" ทุกจุดแสดงผล · ไม่เทียบวัด/รุ่นเชิงลบ · consent ก่อนใช้รูปลูกค้าทำคอนเทนต์ · disclaimer บนใบรายงานทุกใบ
